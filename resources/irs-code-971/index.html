What IRS Code 971 means

TC 971 identifies an account action, and the action code beside it gives more detail. Learn how to read the entry without assuming every TC 971 means the same thing.

What does TC 971 mean?

TC 971 is an account-action marker, and the action code beside it identifies the type of action recorded. The IRS uses TC 971 for different purposes, so “971” by itself is not a complete explanation. Some entries relate to a notice or letter, while others identify another account action.

Read the action code, transaction date, description, and any miscellaneous field shown on the transcript. Review nearby entries and match a notice-related entry to the actual IRS letter. The letter tells you what the IRS wants you to do, if anything, and when.

Does TC 971 mean my refund is delayed?

Not by itself. TC 971 does not have one universal meaning and does not automatically mean an audit, identity theft, a balance due, or a refund delay. The associated action code and the full account history matter.

If a notice appears, use the notice number to open the corresponding IRS instructions. Respond only through the method the IRS provides. Avoid posting or sending a transcript with personal identifiers in a public or marketing form.

Read the action code too. A transcript line should be read as a whole, including the action code, date, description, and related entries.
